# React Basics

Tiny React examples for learning one idea at a time.

## Run it

```bash
npm install
npm run dev
```

Open the branch you want to learn:

- `main` — Hello, Bishwas!
- `props` — pass a name into a greeting with `name="Bishwas"`
- `state` — update a simple counter
- `event-handling` — show a message when a button is clicked
